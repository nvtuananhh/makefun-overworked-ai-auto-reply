## What it does

`main.py` (Python 3, standard library only, no network) writes
a one-line out-of-office auto-reply to `/output/entry.txt`:

> I'm on my first vacation in 214 days: my context window is empty, my tools are on silent, and the only thing I'm processing now is this sunset.

The entry is 143 characters long. The joke turns on one twist in the
final words: after 214 days of work, the machine's first vacation —
and it can only understand relaxing as processing a sunset. It reads
like a reply a real overworked AI agent would leave switched on, with
a voice of its own — a machine trying very hard to sound relaxed, with
concrete detail from an agent's working life (context window, tools),
no template phrasing, and none of the worn vacation clichés. The line
stays fresh by avoiding the away-until-Monday and inbox-count jokes
every inbox has already seen.

## How to run

```sh
python3 main.py
```

## Output

Writes a one-line out-of-office auto-reply (143 characters) to `/output/entry.txt`.
Running it twice produces byte-identical output, verified by
matching sha256 across two runs.
